# 🎮 Jogo Educativo — Mundo do Saber

Plataforma de jogos educativos para crianças de 5 a 10 anos.

## Stack
React + TypeScript + Vite + Firebase Hosting + Firestore + Authentication + Storage + Analytics + Framer Motion + React Router.

## Objetivo
Criar uma experiência divertida para desenvolver conhecimentos escolares e valores positivos, incluindo uma trilha de histórias e ensinamentos bíblicos adequada à faixa etária.

## Desenvolvimento
npm install
npm run dev

## Build
npm run build

## Firebase
Projeto: jogoeducativo-6692a

Após autenticar o Firebase CLI:
firebase use jogoeducativo-6692a
firebase deploy

As regras de Firestore e Storage começam fechadas por segurança. Elas deverão ser abertas somente quando o modelo de autenticação e perfis estiver implementado.
